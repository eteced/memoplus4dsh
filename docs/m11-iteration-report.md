# M11 — 迭代报告（smoke/mini 驱动的五轮优化）

> 日期：2026-09-05 · 供用户审计并决定是否授权全量复测
> 数据：MemoryAgentBench mini 集（CR 6k 档 + LME 1 context，~15-50 题/轮，成本 ≈ 全量 2-5%）+ 自研时间探针 + 分层 smoke
> 准则遵守：全程零 hardcode（所有判断由 LLM 或多语言嵌入完成，语言无关）；未跑全量；评测工具白名单审计全 PASS

## 1. 起点：run-2 的结构性缺陷

对第二轮有效成绩（审计干净的那轮，FC-SH 57.75 / FC-MH 30.25 / LME 56.67）做逐题召回归因（`benchmark/analyze_recall_failures.py`，1100 题）：

- **注入召回率仅 7.7%**——pre-step 注入几乎不工作，成绩靠模型侦探式 memory_search 硬捞；
- 541 道失败题中 68% 是"记忆从未被召回"；
- **实体碎裂**：45.8% 的图节点是重复实体（2820 组重名，William Shakespeare 裂成 35 个）——精确匹配按类型过滤 + 抽取模型类型逐轮翻转 + 嵌入合并未接线；
- **模板/言语噪声霸榜**：官方模板包装文本被抽成记忆事件并因与查询逐字重合霸占 top-k（replay 实证：净查询金事件 #1，包装查询跌出 top-12）；
- 冲突新旧值共检索、新值偏好太弱（上限 0.3 的软偏好）。

## 2. 迭代轮次与每轮发现

### 第 1 轮（mini-1）：实体消解修复 + 噪声压制 v1

- **改动**：类型无关实体合并（精确 + 嵌入路径都去类型过滤）；known_entities 提示带类型；言语行为谓词 ×0.3（**英文词表，后被判定 hardcode 打回**）；注入查询标点启发式提取。
- **结果**：注入召回 7.7%→57.5%（SH 档 **100%**）；重名实体 2820→**0**；sh_6k 90/sh_32k 70（10 题档）。

### 第 2 轮（mini-2）：去 hardcode 的 v2 —— 失败轮，但值回票价

- **改动**：KIND 列语义标记（替代英文词表，✅ 保留至今）；**合并式 LLM 查询分析器**（一次调用出蒸馏+关键词）。
- **结果**：SH 回退 20-30pt。**根因实锤**（live 缓存取证）：合并 prompt 让模型对任务型载荷（"Now Answer the Question: …"）**直接答题**（distilled="Portugal"）而非蒸馏，且关键词为空——注入检索词退化成答案词/模板词。
- **教训**：该用确定性代码的地方不要滥用 LLM；合并多任务的 prompt 脆弱；查询侧 LLM 行为必须可观测（由此补了 debug 日志归档）。

### 第 3 轮（v3 + mini-3）：v3 修复 + supersede 初版

- **v3 设计**：蒸馏 = 标点启发式主路（无法被任务文本带偏）+ LLM **逐字引用**兜底（"引用原问题，不要回答"，仅覆盖无问句标点的长消息）；扩展恢复已验证的独立 prompt；>4000 字符消息跳过注入（ingest 提速 **3 倍**）。
- **supersede 初版**：同（主体, 谓词）撞车 → LLM 裁决"是否更新" → 旧值打标记，检索现在时 ×0.3。
- **结果**：smoke **5/5**、时间探针 **5/5**；但 mini-3 又实锤两个 supersede 缺陷：
  1. **旧值重提反向取代新值**（提及顺序≠信息新旧）→ 修复：**重提守卫**（客体值已存在则视为重提不进裁决）+ **标记传播**（重提继承旧值的 supersede 标记）；
  2. **逐对裁决不可靠**（"rock music→rap rock" 同谓词 4 秒之差却不标）→ 重构：**按关系裁决基数**（"这个关系是单值还是多值"——模型能答的语义属性，时序由提及顺序提供）。

### 第 4 轮（mini-4）：supersede 基数裁决 + via 多跳

- **via 多跳**（`memory_search` 返回 top-3 命中实体的最新邻接事实，`via <实体>` 标记）——针对 mini-3 暴露的"模型搜索只到第一跳"。

## 3. 机制清单（最终形态）

| 机制 | 位置 | 判断者 | 语言 |
|---|---|---|---|
| 实体消解：类型无关精确匹配 + LLM 裁决合并（嵌入粗召回候选） | 写入 | 代码 + LLM | 无关 |
| 言语行为噪声：KIND 列语义标记，检索 ×0.3 | 写入标记 + 检索 | 抽取 LLM | 无关 |
| 指令/元叙述拒收 | 抽取 prompt | 抽取 LLM | 无关 |
| 注入查询蒸馏：标点启发式主路 + LLM 逐字引用兜底 | 检索 | 代码 + LLM | 标点级 |
| 日历 RANGE 时间算子（上周/本月/last week…） | 检索 | 代码（双锚） | 中英 |
| supersede：关系基数裁决 + 重提守卫 + 标记传播 | 写入 | LLM（基数）+ 代码（时序） | 无关 |
| via 多跳邻接事实 | memory_search | 代码（图结构） | 无关 |
| 注入近重复行抑制（Jaccard ≥0.85） | 注入 | 代码（共享分词器） | 无关 |
| 事件同轮去重（崩溃重抽幂等） | 写入 | 代码 | 无关 |
| 长消息（>4000 字符）跳过注入 | 注入 | 代码 | 无关 |

## 4. 评测基建（本轮沉淀）

- **三层验证**：`run-smoke.sh`（1 context × 5 题，5 分钟）→ `run-mini.sh`（CR 6k × 10 + LME 5，~2-3% token）→ 全量（需用户授权）；
- **时间探针** `temporal_probe.py`：固定中文剧本（绝对/相对/双锚/冲突/日程）5 题，分钟级；
- **召回归因器** `analyze_recall_failures.py`：逐题判定 injected/searched/never + 图归因（读/写链路分离）；
- **离线 replay** `replay_retrieval.mjs`：任意查询在任意归档图上的排序复现，零 token；
- 每 context 归档：会话日志 + 记忆图 + debug 日志（含实体合并/supersede/蒸馏的裁决记录）；逐 context 工具白名单审计；
- 轮次隔离：`--run_tag` 结果文件 + 归档目录带轮次，断点续跑按 query_id。
